# Unbound Rockhound — Gem Core mark

Locked product mark: Unbound Infotech **three-bar cyan U** with a **faceted crystal** in the bowl.

- Product name: **Unbound Rockhound**
- Cyan: `#00FFFF` (teal family) on black `#000000`
- Source of truth: [`gem-core.svg`](gem-core.svg) (generated by [`build_gem_core_svg.py`](build_gem_core_svg.py))

## Regenerating WinUI / installer rasters (Linux or Windows)

Requires `rsvg-convert` (`librsvg2-bin`) and Pillow:

```bash
python3 branding/build_gem_core_svg.py
python3 branding/render_assets.py
```

## Regenerating ICO on Windows (optional)

If you want ImageMagick or Visual Studio to rebuild the ICO from the master PNG:

```powershell
# ImageMagick 7
magick branding\gem-core.png -define icon:auto-resize=256,128,64,48,32,16 `
  src\GeoMineralTrace.App\Assets\AppIcon.ico
Copy-Item src\GeoMineralTrace.App\Assets\AppIcon.ico installer\assets\AppIcon.ico -Force

# Then refresh Inno wizard bitmaps (Segoe UI on Windows):
powershell -File installer\Prepare-WizardAssets.ps1
```

Visual Studio: open the WinUI project → **Visual Assets** / **Package.appxmanifest** → generate icons from `branding\gem-core.png`.

Do **not** check in Setup.exe binaries. Package with `scripts\Package-Release.ps1` / `scripts\Build-Installer.ps1` on a Windows machine.
